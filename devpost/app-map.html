This is a reference route through the actual application. The learner has not yet completed a hands-on tour. It describes code and test evidence, not learning outcomes or a submission reflection.

The useful boundary

The AI proposes actions and quotations. Code checks quotation presence and date structure. A person checks interpretation and confirms what may be exported. None of these steps establishes that every obligation was found.

01 · Make a correctionapp/receipt-workspace.tsx

ActionCard

Review details lets you enter a date, add a missed cutoff and confirm the time/offset. An edit goes through editAction and revokes approval.

02 · Check eligibilitylib/receipt.ts

calendarEligible

An item needs matched action evidence, user approval, a confirmed complete date, and a complete cutoff when timed. Original uncertainty remains in its evidence trail.

03 · Create the filelib/export.ts

calendarText

Only eligible items become events. Source quotations, conditions and user corrections go in the description. Date-only items become day markers; timed deadlines are instants.

A practice to reuse

Define an observable rule before coding. Here, “changing the date revokes approval and date confirmation” is implemented by editAction and exercised in tests/receipt.test.ts. When a review found users could not add a missed time, the rule led to a concrete control and a regression check. On another AI project, identify the human decision that must stay explicit, then test that state transition.

To change this, start here

  • Layout, wording labels and review controls: app/receipt-workspace.tsx and app/globals.css.
  • Quotation checks, date rules and approval reset: lib/receipt.ts.
  • Checklist/calendar content and correction provenance: lib/export.ts.
  • AI instructions, request limits and service failures: lib/extraction-service.ts.
  • Synthetic examples: lib/samples.ts. They remain labeled walkthroughs.
Run it again

With Node 22.13+ and dependencies installed, run npm run dev and open its printed local URL. Run npm test and npm run typecheck for the mechanical checks. Live AI additionally needs securely configured server credentials. See the README for setup.
